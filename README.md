## Take the map with you

| Compact navigation | Just the map |
| --- | --- |
| ![Compact mini-map with sample destination](images/v1.26.0/mini-map-compact.png) | ![Map-only view with sample waypoint](images/v1.26.0/mini-map-only.png) |

- **Follow your location:** automatic centering on accepted readings, resume-follow and clear stale indicators.
- **Make it yours:** map-image opacity, marker size/color, trail width/color, label density and independent zone layers. Save up to eight personal layouts.
- **Keep game input available:** passive map-only mode, optional automatic interaction lock and recovery hotkeys. The main window always offers Show/Hide mini-map.
- **Plan the next stop:** named waypoint routes, pin categories, previous/next stops, route sharing and undo removal.
- **Choose your workspace:** compact navigation, expanded exploration or map-only. Open customization separately without squeezing the map away.

Location OCR reads **your own visible Status Report coordinates**. It cannot refresh your position while those coordinates are hidden, reveal other players or read game memory. Navigation is north-up/map-relative, not dinosaur-facing heading or terrain-safe pathfinding. Borderless/windowed play is intended.

## See the matchup

![Dinosaur portraits and linked growth comparison](images/v1.26.0/combat-portraits.png)

Choose two dinosaurs, select their attacks and move the growth sliders. Portraits, measured silhouettes, stats and reference estimates sit together, with detailed assumptions tucked away.

- Separate comparison and attack-calculator workspaces.
- Independent mutation loadouts and conditions for each side.
- Separate direct-hit and bleed estimates, plus optional blood-reserve scenarios.
- Practical combat, diet, water, bleed and survival reference guidance.

**Reference estimates are not fight-winner predictions.** Positioning, cadence, armor, reflection, regeneration and special mechanics are not universally simulated. Unknown effects remain unknown; illustration panels are independently scaled.

## Keep the whole run organized

| Tool | What it helps you do |
| --- | --- |
| Prime checklist | Record attempted, confirmed and still-on-track objectives, with suggested next steps. |
| Lineage & mutations | Track generations and selected mutations; read descriptions before choosing. |
| Routes & Expedition | Combine stops, browse food references, plan mutations, and keep field/family notes. |
| History & replay | Review archived lives, recorded routes and events; import/export runs. |
| Growth Studio | Explore measured growth-stage silhouettes and reference stats with one slider. |
| Compass guide | Identify the game's direction, resource and zone symbols. |
| Profile recovery | Export complete backups and use retained recovery snapshots. |

Open **Routes → Expedition planner** for the planning tools. Food references are not live food detection. Recovery/supply scenarios use rates you measured; journals cannot save or restore an in-game dinosaur.

## Download and get started

1. Back up your complete profile and close Trailguide before upgrading.
2. [Download the Windows installer](https://github.com/roid-apps/Evrima-Trailguide/releases/download/v1.26.0/EvrimaTrailguide-Setup-1.26.0.exe). The [ZIP bundle](https://github.com/roid-apps/Evrima-Trailguide/releases/download/v1.26.0/EvrimaTrailguide-1.26.0-Windows.zip) contains the same installer and notices, **not a portable app**. GitHub's automatic source archives are documentation, not the app.
3. Open **Setup check**, then the game's **Status Report**. Choose **Scan setup → Auto setup** and inspect the previews.
4. Start scanning and choose **Show mini-map**. Reopen the Status Report to refresh your location; hover the growth bar for the precise growth tooltip.

**Windows x64 · Windows 10 build 19041+ · .NET runtime included.** English Windows OCR support may need enabling separately. Normal upgrades preserve per-user settings and history. Back up before downgrading.

**Default hotkeys:** `Ctrl+Shift+M` show/hide · `Ctrl+Shift+I` interactive controls · `Ctrl+Shift+H` map-only. Change them in Overlay options; use the main window for recovery if a hotkey conflicts.

The linked videos introduce the core workflow and predate Glacier. Optional update checks follow GitHub's latest stable release.
