TRACKING AND GROWTH
- Focused tracking regression suite: 216 passed (included in the full suite).
- Long-travel reacquisition requires plausible elapsed travel, complete coordinates,
  corroborating same-frame reads and three separate fresh captures beyond 2 km.
- Stale captures, missing signs, collapsed digits, suspicious altitude and impossible
  jumps remain guarded. Blind-travel allowance remains bounded to five minutes.
- A deterministic probe with 600 seconds of unseen travel and 0.5-second capture
  spacing accepted 1,999/2,000 m travel in 1.0 second and 2,001/4,000 m in 1.5 seconds.
  This tests the confirmation policy, not end-to-end game or OCR performance.
- Failed status-text OCR no longer suppresses the growth stage. Cancellation,
  game focus, run changes, calibration and timestamp freshness remain checked.
- Actual Windows OCR (en-US) processed two supplied saved Status Report images.
  Repeated tests returned exact coordinates for 80 normal reads and 40 verified
  reads, and exact 53.898% / 51.04% growth for all 80 growth reads across two crops.
  These are repeated reads of two images, not a broad image corpus or live game test.
- Offline coordinate pipeline medians were 9-33 ms; corroborating verification
  medians 14-24 ms; growth medians 25-43 ms. Polling, desktop capture and gameplay
  latency are excluded. These numbers are not promised update deadlines.

ONE-CLICK PRIME PLANNING
- Independent workflow and routing run: 87 passed, including 12 new user-workflow
  cases. These overlap the full suite and are not additional independent test totals.
- Covers fresh spawn, stale/missing position, first accepted fix, scanner startup,
  mapped arrivals, manual and server-confirmed objectives, detours, new runs and
  unsupported ruleset changes. Saved pins and route presets are preserved.
- Planner compares route candidates against the older nearest-to-spawn policy,
  applies bounded route improvement and avoids continually reshuffling on tiny moves.
- Headless UI checks cover automatic first-fix route framing, cancellation and
  preservation of later user pan/zoom. Both navigation surfaces receive route updates.
- Mapped sanctuary, migration and patrol visits remain attempts, not server proof.
  Routes use straight-line distances; they are not terrain-safe paths or guarantees
  of globally optimal routes or server-active zones. Diet, nesting, mass migration
  and other Prime requirements need their own checks.

LIMITS AND PUBLICATION

  session was performed for 1.27.1. Headless tests and saved-image OCR do not replace
  native gameplay tests. Earlier native overlay evidence is in the 1.27.0 report.
- Coordinates must be visible/readable in Status Report. Hidden movement cannot be
  tracked; unseen travel remains a gap. A 0.5-second setting is a polling preference.
- Testing does not cover every GPU, monitor/DPI combination, OCR language, custom
  server or all-users/UAC installation. Game and combat values remain references.
- Automatic updates remain opt-in; stable is the default channel. Verified updates
  install only after normal close and successful profile save. No game is force-closed.
- Installer remains unsigned. SHA256 validates bytes against the release; it is
  not a substitute for code signing.
- Publication verifies all four uploaded assets by size and SHA256, checks tag and
  documentation commit, and requires draft=false, prerelease=false and latest=v1.27.1.
